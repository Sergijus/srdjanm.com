# Mobile Sidebar: Smaller & More Subtle

## What We'll Change

The floating social icons on the left side of the screen will become smaller and more subtle on mobile devices, so they don't interfere with your content.

## Visual Changes on Mobile

| Element | Desktop | Mobile |
|---------|---------|--------|
| Icon size | 20px | 16px |
| Button padding | 12px | 8px |
| Background | Semi-transparent dark | More transparent |
| Border | Gold accent | Softer, more subtle |
| Position | 32px from left | 16px from left (tighter to edge) |

## How It Will Look

- **Desktop**: No change — icons stay the same size and prominence
- **Mobile**: Icons will be noticeably smaller and more ghost-like, tucking closer to the screen edge so they don't overlap your text content

The icons remain fully tappable and functional, just with a lighter visual footprint on smaller screens.
